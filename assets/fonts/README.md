# Fonts Directory

This directory contains font files for the Silsilah App.

## Current Fonts:
- **Poppins** - Primary font family
  - Regular (400)
  - Medium (500)
  - SemiBold (600)
  - Bold (700)

## Font Usage:
The Poppins font family is used throughout the app for:
- Headings and titles
- Body text
- UI elements
- Navigation

## Adding New Fonts:
1. Add font files to this directory
2. Update pubspec.yaml with font definitions
3. Update app_theme.dart to use new fonts

## Font Files Needed:
- Poppins-Regular.ttf
- Poppins-Medium.ttf
- Poppins-SemiBold.ttf
- Poppins-Bold.ttf

Note: Font files should be downloaded from Google Fonts or other licensed sources.
