# Images Directory

This directory contains image assets for the Silsilah App.

## Structure:
- `logo/` - App logos and branding
- `icons/` - Custom icons and graphics
- `backgrounds/` - Background images
- `placeholders/` - Placeholder images

## Supported Formats:
- PNG (recommended for icons and graphics)
- JPG (recommended for photos)
- SVG (for scalable graphics)
- WebP (for optimized web images)

## Guidelines:
- Use descriptive filenames
- Optimize images for mobile devices
- Provide multiple resolutions when needed (@1x, @2x, @3x)
- Keep file sizes reasonable for mobile apps
